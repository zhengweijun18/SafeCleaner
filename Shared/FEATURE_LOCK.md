# v4.14 功能锁定基线

从 v4.14 起，macOS Intel、macOS Apple Silicon、macOS Universal 与 Windows
共享同一套产品行为。除操作系统底层路径与系统接口外，不允许平台自行改变交互。

## 四个一级入口

1. 智能扫描
2. 大文件
3. 应用卸载
4. 应用残留

## 扫描规则

- 切换左侧菜单不自动开始扫描。
- 第一次扫描必须点击右侧主按钮。
- 扫描过程中允许切换页面。
- 切换页面不暂停、不取消、不重置原扫描。
- 同一时间只运行一个扫描任务。
- 扫描结果保存到任务所属页面；完成时不强行跳回扫描页。
- 扫描支持暂停 / 继续 / 取消。

## 删除规则

- 不自动清理。
- 用户手动勾选。
- 默认移到 macOS 废纸篓 / Windows 回收站。
- 不提供默认永久删除。
- 高风险项默认不勾选。
- 模糊匹配默认为“人工判断”。

## 交互锁定

所有按钮统一具备：
Default / Hover / Pressed / Selected / Disabled。
